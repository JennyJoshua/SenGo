# SenGo

**Your journey can deliver more.**

SenGo is a Papua New Guinea-first peer-to-peer logistics marketplace concept connecting people who need to send packages with independent travellers who have available capacity on journeys they are already making.

## Project status

This repository is being established. The current work is limited to approved product documentation and development foundations. No delivery service is live.

## Approved direction

- Marketplace model; SenGo does not initially own or operate a transport fleet.
- Controlled pilot before national expansion.
- Road, sea, air and walking represented in the architecture, each subject to separate eligibility and regulatory controls.
- Direct sender-to-traveller payments initially; SenGo does not hold funds.
- Deterministic matching for the initial MVP.
- Receiver confirmation required before a delivery is marked complete.
- Mobile-first and low-bandwidth-aware design.

## Current phase

Batch 0 — project foundation, product rules and PNG legal/safety assessment.

See [docs/](docs/) as project documentation is added and the [GitHub Issues](https://github.com/JennyJoshua/SenGo/issues) for the implementation backlog.

## Important

This project is not legal clearance to carry any category of goods. Commercial launch and activation of each transport mode are subject to appropriate PNG legal, regulatory and safety assessment.
