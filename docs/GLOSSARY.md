# SenGo Product Glossary

| Term | Meaning |
|---|---|
| Sender | User who creates a request to have a package transported. |
| Traveller | Independent person who publishes a journey and may agree to carry an eligible package. |
| Receiver | Person designated to receive a package and confirm delivery. |
| Administrator | Authorised operator who manages platform safety and operations. |
| Travel intention / journey | A traveller's declared route, dates, transport mode and available capacity. |
| Public journey | A journey eligible to appear in public discovery, subject to privacy rules. |
| Private journey | A journey excluded from public search but eligible for controlled private matching. |
| Delivery request | A sender's structured request to transport a declared package. |
| Package record | Structured description and evidence associated with a package. |
| Match | A candidate relationship between a delivery request and a compatible journey. A match is not yet an agreement. |
| Delivery agreement | Terms explicitly accepted by both sender and traveller before handover. |
| Custody event | Auditable record of a package handover or change in custody/status. |
| Tracking reference | Unique reference used to identify a delivery without exposing private details. |
| Handover PIN | One-time code used to confirm an authorised package transfer. |
| Delivery confirmation | Receiver's confirmation that the package was received. |
| Reported payment status | A status entered by a participant; not proof that SenGo processed or independently verified payment. |
| Restricted goods | Items that may be carried only under specified conditions or after review. |
| Prohibited goods | Items that must not be accepted through the platform. |
| Pilot | Limited, controlled initial operation used to validate product, safety and operational assumptions. |
| MVP | Minimum viable product: the smallest release that proves the approved core delivery workflow. |

## Naming rule

Use these terms consistently in product copy, database design, API contracts, tests and support documentation. Avoid using “courier” to imply that SenGo employs or operates a delivery fleet.
